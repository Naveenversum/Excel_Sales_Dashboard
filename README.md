# Sales Dashboard – Excel

## Project Overview

This project focuses on analyzing sales data and creating an interactive sales dashboard using Excel/LibreOffice Calc.

The objective was to clean the raw sales data, analyze key sales metrics, and present the results using Pivot Tables, KPIs, and charts.

## Tools Used

- Excel / LibreOffice Calc
- Pivot Tables
- Excel/Calc formulas
- Charts

## Dataset

The dataset contains approximately 50,000 sales records with information such as:

- Order ID
- Order Date
- Customer Name
- City
- State
- Product
- Category
- Salesperson
- Quantity
- Price
- Discount
- Total Sales
- Payment Mode
- Region

## Data Cleaning

The raw data was prepared before analysis by:

- Checking for duplicate records
- Checking for blank values
- Removing unnecessary spaces
- Reviewing missing Payment Mode values
- Validating the sales data

## Analysis Performed

Created Pivot Tables to analyze:

- Sales by Region
- Sales by Product
- Sales by Salesperson
- Sales by Payment Mode

## Key KPIs

The dashboard includes:

- Total Sales
- Total Orders
- Total Quantity

## Dashboard

The final dashboard uses charts and KPI cards to present the sales performance in an easy-to-understand format.
